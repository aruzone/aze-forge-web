AzeForge compiler and renderer

Technical documents, built from plain text.

AzeForge is the compiler and renderer for AzeMark. Validate structured technical Source, then render HTML, SVG, PNG, or PDF.

Install AzeForgeRead the docs
npm install @aruzone/aze-forge

Built for structured work

AzeMark adds typed directives for equations, data, diagrams, engineering notation, and document composition while keeping prose in Markdown.

01 / Capabilities

Compiler contracts instead of plugin guesswork.

The 26-directive grammar comes from the same registered definitions the compiler validates.

  • Readable SourceMarkdown prose and typed AzeMark directives stay in one .aze.md file.
  • Corrective diagnosticsErrors carry codes, severity, locations, suggestions, and optional edits.
  • Deterministic outputThe same valid Source and render options produce byte-identical Artifacts.
  • Fail-closed renderingInvalid Source publishes no partial Artifact and does not replace a previous output.
