AzeMark 2 · AzeForge 0.6.3

Language foundations.

AzeMark combines YAML front matter, Markdown prose, and typed directives in one .aze.md Source.

Front matter

Open the document with YAML between --- delimiters. Every 0.6.3 guide and agent-authored Source declares the integer azemark: 2. Verified optional keys include title, author, theme, outputs, defaults, and citation-style.

Do not infer semantics. The 0.6.3 compiler exposes the defaults and outputs keys but does not publish their full behavior in the grammar.

Directive fences

An outer directive uses exactly four colons. Five colons are invalid and must not be normalized. Put header fields before ---- and body data after it. A figure uses nested :: child blocks.

:::: callout
variant: note
title: Check the Source
----
Validate before rendering.
::::

Identifiers and nesting

Directive identifiers have document scope and match ^[a-z][a-z0-9]*(?:-[a-z0-9]+)*$. Maximum directive nesting depth is 8. A line beginning with // is a comment.

Composition

The canonical composition Source demonstrates @id cross-references, citations, endnotes, numbered figures, nested equations, and bibliography entries.

Bounded claim. 0.6.3 has one verified citation example and one verified endnote example, but the generated grammar does not define their complete syntax. Reuse the canonical Source forms; do not invent variants.

Rendering

AzeForge parses and validates the complete Source before rendering. HTML does not need a browser engine. SVG, PNG, PDF, Mermaid, and native visual directives need the pinned browser capability. TeX also needs the configured external adapter.
