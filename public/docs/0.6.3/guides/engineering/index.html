Authoring workflow

  1. Start from the smallest relevant block in the canonical Source.
  2. Give referenced declarations stable kebab-case identifiers.
  3. Run azeforge validate before rendering.
  4. Apply diagnostic suggestions to the reported location rather than guessing at a replacement field.
