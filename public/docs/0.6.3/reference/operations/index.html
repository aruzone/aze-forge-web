Operations.

AzeForge 0.6.3 supports analyze, compile, and format operations. The hosted service exposes those operations through its authenticated /v1 API.

OperationResultKey options
analyzeDocument diagnostics and optional Document dataincludeDocument
compileRequested Artifact after successful validationformat, theme, assets, includeDocument
formatA deterministic formatted-Source proposalCLI --write, --check, or --stdin
migrateUnavailable in 0.6.3The service rejects it rather than translating Source

CLI commands

azeforge validate document.aze.md --diagnostics json
azeforge render document.aze.md --output document.pdf
azeforge format document.aze.md --check
