AzeMark 2 · AzeForge 0.6.3

Notation codex.

AzeForge is a library for both humans and AI agents. People read this page to author valid AzeMark; agents treat it as the human companion to grammar.json and the AI-authoring contract. Every spelling below is verified against the pinned 0.6.3 compiler Sources and generated grammar. Copy the AzeMark column verbatim; do not invent near-miss keys.

Closed grammar. Unknown words of three or more letters are diagnostics, not new functions. Use only the registered names on this page.

Authoring workflow

  1. Find the rendered form on this page.
  2. Copy the AzeMark spelling into a four-colon outer fence or a record-list Block.
  3. Run azeforge validate before rendering.
  4. Read the generated directive reference for the complete field contract.
