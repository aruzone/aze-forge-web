Version contract.

These docs never use “latest” as a compatibility promise. Every artifact names the compiler, source language, document schema, and grammar schema.

Plugin versions

Equation and table use plugin source/data version 2. Every other 0.6.2 directive publishes plugin version 1. Plugin version numbers are not AzeMark language versions.

Future releases

A future compiler release receives a separate documentation tree. 0.6.2 does not publish migration rules for a future AzeMark version, and its migrate operation is unavailable.
