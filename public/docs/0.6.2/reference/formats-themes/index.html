Formats and themes.

The pinned capability document advertises four output formats and three themes.

Formats

HTMLSelf-contained HTML; no browser engine required
SVGRendered through the pinned browser capability
PNGRendered through the pinned browser capability
PDFRendered through the pinned browser capability

PDF output is capped at 200 pages. PNG uses device scale factor 2. Successful Artifacts include the content hash of their Document.

Pinned engines

The 0.6.2 capability document pins Chrome Headless Shell 152.0.7977.75, KaTeX 0.18.5, and Mermaid 11.17.2. Read capabilities.json for the full engine registry.
